# Source contradiction matrix

Each row below is one question, and each column is one source.

- **Plain text in a cell** is what that source documents. It is a fact *about the source*: what it says
  or shows.
- **Text in *italics*** is a reading of that source. It is not the source's own words.
- **"—"** means the source says nothing on the question.
- **"n/r"** means the source was not read for this question.

**Independence.** Three source families stand behind the columns:

1. **The print.**
2. **ShabadOS 4.8.7 and BaniDB**, which form one lineage for grouping.
3. **The commentaries:** Sahib Singh's Darpan and the Faridkot Teeka. Both are read only as
   transcribed in ShabadOS 4.8.7.

A ShabadOS cell and a BaniDB cell that agree are **not** independent corroboration of each other.

The Encyclopaedia of Sikhism (EoS) cells cite volume and page from `EVIDENCE-LEDGER.md` § EoS. Every
page cited there was read as an image. The EoS is a fourth family, but it contradicts itself in places.
